# 不做手机控：为什么不接入

不做手机控（`C:\开发\不做手机控`）是 Android 本地自律工具：一次性锁机、每日总限额、
独立 APP 限额、循环监督。它的核心设计承诺是**彻底离线**——

- APK 不声明 `INTERNET` / `AD_ID` 权限；
- 全部规则存本机 `SharedPreferences`，无账号、无云同步、无统计上报；
- 系统备份也被禁用。

「手机上的使用数据永远不出手机」正是这个应用的价值。给它加联网通道去喂看板，
等于拆掉它的产品边界，所以**看板有意不接入它，这是决定而不是欠账**。

## 如果哪天想看它的数据

保持离线承诺的前提下只有手动路径：项目自带
`tools/export_local_logs.ps1 -Serial <device>`，经开发期 ADB 把本地日志导出到电脑。
理论上可以再写一个解析器把导出结果转成 `remote` widget 的 JSON——但那是
「用户主动用数据线导一次」的快照，不是实时监控，且需要你明确决定要这么做。

在那之前，它在板上的存在方式与随心一听相同：作为「开发」分组项目进度卡里的
一个仓库条目。
