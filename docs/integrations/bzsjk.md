# 不做手机控：受限云同步，不提供 MCP

不做手机控（`C:\开发\不做手机控`）是 Android 本地自律工具：一次性锁机、每日总限额、
独立 APP 限额和循环监督。规则、统计、白名单与锁机事实仍只保存在手机本机。

当前版本不再是完全断网产品。它允许唯一的业务网络出口：作为 FocusLink 第四端，使用
设备凭据读取 FocusLink 云端 `/v1/live` 与 `/v1/live/wait`，把专注状态接入现有监督循环。
该通道是只读的，不上传本机规则、应用使用数据或统计历史，也不恢复广告、登录、支付、
厂商更新、云恢复或遥测链路。

## 当前边界

- **无 MCP**：ChatGPT 不能读取或控制本机监督规则、统计和锁机状态；
- **同步不完整**：只消费 FocusLink 实时状态，不做本机数据的双向同步；
- **桌面卡片仅作边界提示**：固定保留「不做手机控」卡片，但没有手机业务数据时只显示
  「仅本机，数据待接入」以及 FocusLink 数据是否可读，不冒充完整运行状态；
- **手动诊断**：`tools/export_local_logs.ps1 -Serial <device>` 仅在用户主动连接测试设备时
  导出脱敏日志。

源码已备份到 private 仓库 `666poyi666-collab/BuZuoShouJiKong`。基线 APK、本地工具链、
发布 APK、签名材料和设备标识不进入 Git。
