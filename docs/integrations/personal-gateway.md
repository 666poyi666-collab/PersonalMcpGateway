# Personal Gateway 磁贴

这张磁贴属于 `PersonalMcpGateway` 自己。它不是其他项目数据的汇总卡，也不是四个大数字
组成的占位板；它表达网关真正负责的事情：本机 MCP 路由、Secure Tunnel、Windows 服务
保活、全链路巡检和故障恢复。

## 数据面

全部数据来自同一进程生成的 `/admin/dashboard-data` 快照，不增加网络请求：

- `targets`：四条项目路由的 MCP、Tunnel、Windows 服务状态与探测延迟；
- `gateway`：版本、在线时长、累计调用和失败数；
- `summary` / `activity.hourly`：24 小时调用量、成功率与逐小时流量；
- `fleet.watchdog`：`PoyiFleetWatchdog` 状态和一键修复能力；
- `errors` / `events`：最近的脱敏错误与链路状态变化。

看板只展示运维事实，不读取密钥、日志正文、日记内容、训练轨迹或其他项目的私有业务数据。

## 呈现风格：Routing Fabric（`gateway`）

- 黑色交换机背板、32px 淡网格和硬边分区，对应常驻本机的路由基础设施；
- 青色表示数据通道，绿色表示可用和自愈，琥珀色表示降级，红色只用于真实故障；
- 顶部四段路由链依次表示项目连接、本机服务、安全连接、自动修复；在线链路有克制的包流动动画；
- 中部显示 24 小时调用、成功率、全链路探测耗时和运行时长；
- 下部是 8 个 Windows 服务的服务状态、24 小时流量轨和最近一次故障/恢复信号；
- 不使用装饰性圆卡和大面积空白，所有区域都对应一个可诊断的运行事实。

## 尺寸规则

| 尺寸 | 内容 |
| --- | --- |
| 大 / 高 | 完整路由、四项指标、四条项目线路、流量轨和最近信号 |
| 中等高度 | 保留路由、指标、服务矩阵和流量，隐藏信号详情 |
| 窄 | 指标改为两列，服务行只保留项目名与状态 |
| 短 | 只保留路由和核心指标 |
| 微型 | 只显示名称；外层看板继续负责状态、拖动和缩放 |

这张卡拥有独立原生窗口，位置、尺寸和显隐不会重排其他卡；管理面板只负责开关卡片，
本文件只约束卡片内部。
