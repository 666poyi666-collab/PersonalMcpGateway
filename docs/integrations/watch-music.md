# 随心一听（手表音乐）接入

随心一听（`C:\开发\手表音乐软件`）是 OWW221 上的音乐播放器：以现有母版为基础，
通过独立 `network-bridge` dex 接入网易云账号、资料库与实时音频，配歌词页、
分档音质与 512MB 分块缓存。

## 现状：暂无常驻数据面

它运行在手表上，没有手机/PC 侧常驻服务，也没有 MCP。**当前接入方式是开发态呈现**——
放进「开发」分组的项目进度卡，跟踪它的仓库活跃度：

```yaml
  - id: projects
    type: projects
    title: 项目进度
    group: 开发
    options:
      repos:
        - C:\开发\手表音乐软件
```

## 将来的实时呈现（路线，不是现状）

想让「正在播放」上墙，需要一个数据面，两条可选路：

1. **手机/PC 桥**：类似间歇跑的手机门面——手表媒体会话状态经局域网上报到一个
   本机小服务，再以 `remote` widget 的 JSON 契约喂给看板（`kind: keyvalue`：
   曲名 / 歌手 / 音质档 / 播放位置）。工程量最小、边界最清晰。
2. **独立 MCP**：如果以后希望 ChatGPT 也能查播放状态，按 Watch MCP 的模板做
   独立 MCP + 专属 Tunnel，看板照常用 `mcp` widget 接。

若做，风格建议沿用 `sport` 表盘底（同一块手表），accent 换成播放器母版的主题色，
封面缩略图需要看板先支持 image kind——列入看板路线而不是现在实现。
